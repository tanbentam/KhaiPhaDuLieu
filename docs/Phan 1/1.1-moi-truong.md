# 1.1 Môi trường Python cho phần M2

## Mục tiêu

Có môi trường Python chạy được K-Means, DBSCAN (và HDBSCAN để benchmark). Có `requirements.txt` để thành viên khác cài trên máy cá nhân hoặc trên Google Colab.

## Đã làm

- Dùng venv có sẵn `D:\3\ai_env` (Python 3.10.6). Cài thêm `pyarrow`, `folium`, `seaborn`, `hdbscan`. `hdbscan` cài được bằng bản wheel dựng sẵn (`--only-binary`), không cần Visual C++ Build Tools.
- Ghi cấu hình máy chạy benchmark: AMD Ryzen 7 7840H (8 nhân, 16 luồng), RAM 15,2 GB, RTX 4060. scikit-learn và hdbscan chỉ chạy trên CPU, không dùng GPU.
- Tạo `requirements.txt` ở gốc repo:
  - Dùng dải phiên bản (ví dụ `numpy>=2.0,<3`), không ghim cứng, để Colab không phải cài lại numpy/pandas.
  - Cuối file ghi các phiên bản đã kiểm thử.
  - `ipykernel` để ở dạng comment, chỉ cài trên máy cá nhân.
  - Các gói không gian (geopandas, pyproj, shapely) thuộc phần M1, chưa thêm.

## Kiểm thử

- Import đủ 12 gói trong `ai_env`. Phiên bản: numpy 2.2.6, pandas 2.3.3, pyarrow 25.0.1, scipy 1.15.3, scikit-learn 1.7.2, hdbscan 0.8.44, matplotlib 3.10.9, seaborn 0.13.2, folium 0.20.0, psutil 7.2.2, PyYAML 6.0.3, ipykernel 7.3.0.
- Chạy thử `hdbscan.HDBSCAN(min_cluster_size=30)` trên dữ liệu giả lập `make_blobs` (2000 điểm, 4 tâm). Kết quả tìm đúng 4 cụm.
- Chạy `pip install --dry-run --ignore-installed --only-binary=:all: -r requirements.txt` trên Windows, Python 3.10. Pip giải được đủ gói (exit 0), toàn bộ đều có bản wheel dựng sẵn.
- Lỗi phát hiện khi thử: phiên bản đầu của `requirements.txt` có ghi chú tiếng Việt có dấu. pip 22.2 trên Windows đọc file bằng mã cp1252 nên báo `UnicodeDecodeError`. Đã sửa bằng cách chỉ dùng ký tự ASCII trong file và kiểm tra lại bằng cách decode ASCII.
- **Chưa kiểm:** cài trên Colab (Linux, Python 3.12). Thử giả lập bằng `pip --platform manylinux --python-version` thì pip 22 rơi vào vòng thử lùi phiên bản quá lâu (hơn 10 phút), nên đã dừng. Cần chạy thật một lần trên Colab.

## Lưu ý

- Theo spec, `requirements.txt` chung thuộc phần M4 (README, môi trường). File này là bản khởi đầu do M2 tạo. M1, M3, M4 bổ sung gói của phần mình vào đây, không tạo file riêng.
- Giữ `requirements.txt` chỉ có ký tự ASCII.
- pip trong `ai_env` là bản cũ (22.2.1). Không bắt buộc nâng cấp. Nếu nâng cấp thì chạy `python -m pip install --upgrade pip`.
- Khi chạy benchmark chính thức, lưu thêm `pip freeze` để ghi lại chính xác phiên bản đã dùng.
- Không có dữ liệu thử nào còn sót lại. Thư mục tạm của pip nằm trong scratchpad, không nằm trong repo.
