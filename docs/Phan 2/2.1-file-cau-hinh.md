# 2.1 File cấu hình thí nghiệm

## Mục tiêu

Có một file cấu hình chung (seed, CRS, đường dẫn, lát cắt thời gian, cỡ mẫu, lưới tham số K-Means và DBSCAN) và hàm đọc file đó. Hàm phải tự kiểm tra lỗi và chạy được cả trên máy cá nhân lẫn Colab.

## Đã làm

- `config/experiment.yaml`: giá trị khởi điểm lấy theo BA Spec v1.1 (Phụ lục A2):
  - seed 42, EPSG:26916, feature `[x_m, y_m]`.
  - Đường dẫn theo đề xuất ở `docs/dinh-dang-du-lieu.md`.
  - 3 lát cắt thời gian.
  - Mẫu pilot 10k/30k/50k, mẫu mục tiêu 100k.
  - K từ 2 đến 15; eps 150–1000 m; min_samples 5/10/15/20.
  - Để trống mục `hdbscan` cho M3 bổ sung.
- `src/config.py`:
  - `find_repo_root()`: tự tìm gốc repo nên chạy được từ bất kỳ thư mục con nào (ví dụ `notebooks/`) và trên Colab.
  - `load_config()`, `resolve_path()`, `slice_hours()`.
  - `validate_config()`: gom mọi lỗi rồi báo một lần. Kiểm tra đường dẫn tuyệt đối hoặc có `..`, lát cắt chồng lấn, giá trị K/eps/min_samples sai miền, kiểu dữ liệu.
- `src/__init__.py` để import được dạng `from src.config import ...`.

## File thay đổi

- `config/experiment.yaml` (mới)
- `src/__init__.py`, `src/config.py` (mới)
- `docs/Phan 2/2.1-file-cau-hinh.md` (mới), `docs/logs.md`, `docs/checklist-m2.md`

## Lưu ý

- Các giá trị trong YAML là cấu hình khởi điểm theo spec, sẽ chỉnh sau khi xem đồ thị elbow và k-distance (Phần 3–4).
- Đường dẫn và định nghĩa lát cắt đang dựa trên đề xuất 1.2, chưa được nhóm chốt. Nếu M1 đổi thì chỉ cần sửa YAML.
- Thư mục `src/` và `config/` theo mục 5.3 của spec. Cấu trúc repo thuộc phần M4/M1, ghi nhận đây là phần M2 tạo trước.
- Đề xuất cho M4: thêm `.gitignore` gồm `__pycache__/`, `data/raw/`, `data/interim/`, `.ipynb_checkpoints/` trước khi có notebook và dữ liệu.
- Không có dữ liệu thử nào còn trong repo.
